# Architecture Decision Records (ADRs)

ADRs capture durable choices and the reasoning behind them. Proposed decisions are not implementation evidence.

| ADR | Decision | Status |
|---|---|---|
| [0001 — Local-first modular monolith](0001-local-first-modular-monolith.md) | Keep one deployable backend and local household scope | Accepted baseline |

When a decision changes, create a new ADR or supersede the old one; do not silently rewrite history.
